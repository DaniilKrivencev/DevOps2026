## Способ 1 — Docker (рекомендуется, самый простой)

### Требования
- [Docker Desktop](https://www.docker.com/products/docker-desktop/) установлен и запущен

### Шаги

**1. Перейди в папку проекта**
```bash
cd DevOps
```

**2. Создай файл `.env` из шаблона**
```bash
# Windows (PowerShell)
Copy-Item .env.example .env

# или Windows (CMD)
copy .env.example .env
```

Открой `.env` в любом редакторе и при желании смени пароли (по умолчанию всё уже настроено):
```
POSTGRES_USER=duma_user
POSTGRES_PASSWORD=changeme        ← можно сменить
POSTGRES_DB=city_duma
DATABASE_URL=postgresql+asyncpg://duma_user:changeme@db:5432/city_duma
SECRET_KEY=change-me-in-production  ← обязательно смени в проде
```

**3. Запусти контейнеры**
```bash
make up
```

> Первый запуск занимает 1–2 минуты (скачивает образы и собирает приложение).

Docker автоматически:
- Поднимет PostgreSQL
- Применит миграции (`alembic upgrade head`)
- Запустит приложение

**4. Открой в браузере**

| Адрес | Что открывается |
|-------|----------------|
| http://localhost:8000 | Веб-интерфейс (главная) |
| http://localhost:8000/ui/deputies | Депутаты |
| http://localhost:8000/ui/commissions | Комиссии |
| http://localhost:8000/ui/sessions | Заседания |
| http://localhost:8000/ui/attendance | Посещаемость |
| http://localhost:8000/docs | Swagger UI (API) |
| http://localhost:8000/health | Проверка работоспособности |

**5. Проверь работоспособность**
```bash
make container-check
```

Ожидаемый ответ:
```json
{
  "status": "ok",
  "database": "ok",
  "version": "0.1.0"
}
```

**6. Остановка**
```bash
make down          # остановить (данные сохраняются)
make down-volumes  # остановить + удалить данные БД
```

## Способ 2 — Локально без Docker

### Требования
- Python 3.12+
- PostgreSQL 14+ (установлен и запущен локально)

### Шаги

**1. Создай виртуальное окружение и установи зависимости**
```bash
make setup
```

Или вручную:
```bash
python -m venv .venv

# Windows (PowerShell)
.venv\Scripts\Activate.ps1

# Windows (CMD)
.venv\Scripts\activate.bat

pip install -r requirements.txt
```

**2. Создай базу данных в PostgreSQL**
```sql
-- Выполни в psql или pgAdmin
CREATE USER duma_user WITH PASSWORD 'changeme';
CREATE DATABASE city_duma OWNER duma_user;
```

**3. Создай файл `.env`**
```bash
copy .env.example .env
```

Если PostgreSQL запущен локально, измени `POSTGRES_HOST` и `DATABASE_URL`:
```
POSTGRES_HOST=localhost
DATABASE_URL=postgresql+asyncpg://duma_user:changeme@localhost:5432/city_duma
```

**4. Активируй venv (если ещё не активирован)**
```bash
# PowerShell
.venv\Scripts\Activate.ps1
```

**5. Примени миграции**
```bash
make migrate
```

**6. Запусти приложение**
```bash
make run
```

Приложение запустится на http://localhost:8000 с автоперезагрузкой при изменениях.

## Запуск тестов

> Тесты используют SQLite и **не требуют PostgreSQL**.

```bash
# Установи дополнительную зависимость (один раз)
pip install aiosqlite

make test
```

## Резервное копирование и восстановление

```bash
# Создать резервную копию (нужен запущенный Docker)
make backup
# Файл сохранится в backups/dump_YYYYMMDD_HHmmss.sql

# Восстановить из резервной копии
make restore BACKUP=backups/dump_20260914_120000.sql
```

## Частые проблемы

| Проблема | Решение |
|----------|---------|
| `make` не найден в Windows | Установи [Make for Windows](https://gnuwin32.sourceforge.net/packages/make.htm) или используй Git Bash |
| Порт 8000 занят | Измени `ports: "8001:8000"` в `docker-compose.yml` |
| Порт 5432 занят | Измени `ports: "5433:5432"` в `docker-compose.yml` |
| Docker не запущен | Запусти Docker Desktop и дождись зелёного значка |
| `permission denied` при `Activate.ps1` | Выполни: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| БД не создалась | Убедись, что сервис `migrate` завершился успешно: `docker compose logs migrate` |
| Ошибка `DATABASE_URL` | Убедись, что файл `.env` существует и не пустой |
