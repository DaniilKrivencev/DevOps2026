# Инструкция по запуску — Городская Дума

## Способ 1 — Docker (ЛР4)

Нужен Docker Engine с плагином Compose (Docker Desktop в Windows/macOS или `deploy/install_docker.sh` в Linux).

```bash
cp .env.example .env           # Windows PowerShell: Copy-Item .env.example .env
# в .env задать POSTGRES_PASSWORD и APP_AUTH_USERS (логин:пароль:роль)
make docker-up                 # без make: docker compose up -d --build --wait
```

| Адрес | Что открывается |
|-------|----------------|
| http://localhost:8080 | веб-интерфейс |
| http://localhost:8080/docs | Swagger UI (API) |
| http://localhost:8080/health | проверка работоспособности (+ id экземпляра) |
| http://localhost:8080/api/v1/auth/me | проверка входа: логин и роль (admin / secretary) |
| http://localhost:8080/nginx-health | проверка самого nginx (без приложения) |

Изменения (создание, удаление) требуют входа — браузер спросит логин и пароль из `APP_AUTH_USERS`.

```bash
make docker-ps                 # состояние и healthcheck
make docker-logs               # журналы
make docker-backup             # резервная копия БД → backups/
make docker-restore BACKUP=backups/pg_<время>.dump
make docker-down               # остановить (данные в volume сохраняются)
make container-check           # полная проверка контейнерного окружения
```

## Способ 2 — локально без Docker (ЛР3)

Нужен Python 3.12+. По умолчанию используется SQLite-файл — PostgreSQL не обязателен.

```bash
./setup.sh                     # venv, зависимости, .env, миграции, make verify
make run                       # http://localhost:8000, демо-учётки admin/admin и secretary/secretary
```

Для PostgreSQL задайте в `.env`:
`DATABASE_URL=postgresql+asyncpg://<пользователь>:<пароль>@localhost:5432/city_duma`, затем `make migrate`.

## Проверки

```bash
make verify                    # policy → lint → sast → migrate-check → test → mutation
make test                      # только тесты (отчёты в reports/)
make backup / make restore BACKUP=backups/<файл>
```
